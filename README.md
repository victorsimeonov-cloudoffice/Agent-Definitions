This project hosts several no-code custom agents.
To be more precise, the agent definitions, or agent instructions, or effectively agent source code in natural language for several custom no-code agents I've been creating in the Gemini Enterprise agentic environment in its agent designer no-code agent editor/agent-building environment.

This repository is totally a work in progress. Expect new agents to be added here, potentially on a daily basis or every few days. So keep an eye on it.

A list of some common abbreviations and naming conventions to help you navigate:
- GE == Gemini Enterprise
- NCA == No Code Agent
- there will be more, for certain.
